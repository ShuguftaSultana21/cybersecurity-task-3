# cybersecurity-task-3
Networking Basics for Cybersecurity

Tool Used:
Wireshark

What I Did:
- Installed Wireshark
- Captured live network traffic
- Applied filters for TCP, DNS, HTTP, and TLS
- Observed TCP three-way handshake
- Identified encrypted and plain-text traffic

Observations:
- DNS converts domain names into IP addresses
- TCP uses a three-way handshake (SYN, SYN-ACK, ACK)
- HTTP traffic is visible in plain text
- HTTPS traffic is encrypted and secure
- Packet sniffing helps in analyzing network behavior
